# Changelog

Release history for the Skatehive mobile app.

---

## Latest

### Spot Map — browser access
The Spot Map is now accessible on mobile via the browser at [skatehive.app](https://skatehive.app). Native in-app integration is in development.

---

## How to update

**iOS:** Open the App Store → tap your profile icon → scroll to see pending updates → update Skatehive.

**Android:** Google Play support is coming soon.

---

## Report an issue

Found a bug in the latest version? Report it:
- **Discord:** [#bugs channel](https://discord.gg/skatehive)
- **GitHub:** [Open an issue](https://github.com/SkateHive/mobileapp/issues)

Include your app version (visible in **Profile → Settings → About**), device model, and OS version.
