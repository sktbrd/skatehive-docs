# Devs

Building on or contributing to SkateHive? Start here.

SkateHive 3.0 is open source (Next.js 15 + Chakra UI, Hive blockchain, with
Farcaster and Ethereum/Base integrations). This section covers how to run, fork,
and extend the app.

- **[Fork SkateHive 3.0](./fork-skatehive)** — beginner-friendly guide to clone,
  configure, and run the app locally.
- **[Application Overview](./app-features)** — a tour of the platform's features
  and how the pieces fit together.

Want to help? Jump into the [repo](https://github.com/SkateHive/skatehive3.0) and
say hi in the community channels.
