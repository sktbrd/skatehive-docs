# Primeiros Passos

### Onde baixo o app?

- **iOS:** [App Store](https://apps.apple.com/app/skatehive/id6738086962)
- **Android:** Google Play (em breve)

---

### Preciso de uma conta HIVE para usar o app?

Sim, para postar, votar, comentar ou ganhar recompensas você precisa de uma conta HIVE. Você pode navegar pelo feed e assistir vídeos no **Modo Espectador** sem fazer login.

Você pode criar uma conta HIVE de duas formas:
- **Com e-mail** — cadastre-se direto dentro do app. Rápido e sem precisar de conhecimento em cripto.
- **Via wallet.hive.io** — para quem quer controle total desde o início.

[Criar conta HIVE →](../../../Get%20Started/create-account.md)

---

### Posso experimentar o app sem criar uma conta?

Sim. Abra o app e toque em **Continuar como Visitante** (Modo Espectador). Você pode navegar pelo feed, assistir vídeos e explorar perfis — sem precisar de conta. Para interagir com o conteúdo é necessário fazer login.
