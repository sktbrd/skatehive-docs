# Criando Conteúdo

### Como crio um post?

Toque na aba **+** (Criar) na parte inferior da tela. Você pode escolher entre:

- **Artigo** — post longo com suporte a Markdown, ideal para write-ups completos com imagens
- **Snap** — post curto e rápido para atualizações, clips ou fotos

Preencha o título, conteúdo e tags, depois toque em **Publicar**.

---

### Qual a diferença entre Artigo e Snap?

| | Artigo | Snap |
|---|---|---|
| Tamanho | Longo | Curto / atualização rápida |
| Formatação | Markdown completo | Texto básico |
| Ideal para | Tutoriais, relatos de viagem | Clips rápidos, updates |
| Tags | Múltiplas | Menos |

Ambos são armazenados na blockchain HIVE e podem gerar recompensas.

---

### Quais tags devo usar?

Sempre inclua **`#skatehive`** como tag — ela garante que seu post apareça no feed do Skatehive. Adicione outras tags relevantes como `#skating`, `#streetskating` ou tags de localização para alcançar mais pessoas.

---

### Posso editar um post depois de publicar?

Sim, com limitações. O HIVE permite editar posts dentro de **7 dias** da publicação. Após o fechamento da janela de pagamento, edições ainda são registradas na chain mas a versão original também é preservada. Toque no menu de três pontos no seu post → **Editar**.
