# Changelog

Histórico de versões do app mobile do Skatehive.

---

## Mais recente

### Mapa de Picos — acesso via browser
O Mapa de Picos agora é acessível no celular via browser em [skatehive.app](https://skatehive.app). A integração nativa no app está em desenvolvimento.

---

## Como atualizar

**iOS:** Abra a App Store → toque no seu ícone de perfil → role para ver atualizações pendentes → atualize o Skatehive.

**Android:** Suporte ao Google Play em breve.

---

## Reportar um problema

Encontrou um bug na última versão? Reporte:
- **Discord:** [canal #bugs](https://discord.gg/skatehive)
- **GitHub:** [Abrir uma issue](https://github.com/SkateHive/mobileapp/issues)

Inclua a versão do app (visível em **Perfil → Configurações → Sobre**), modelo do dispositivo e versão do sistema.
